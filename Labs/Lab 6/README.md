1. In your own words, what is the key difference between a regression problem and a classification problem?

- The main difference is the type of output. Regression is used when you want to predict a continuous numerical value (like a price, weight, or temperature). Classification is used when you want to predict a discrete category or label (like "Yes/No," "Spam/Not Spam," or "Survived/Died").

2. The LinearRegression model has an attribute called .coef_. After you train the model, print lr_model.coef_. What do these numbers represent?These numbers represent the coefficients (or weights) for each input feature ($Age$ and $Pclass$). They tell you how much the predicted $Fare$ changes for every one-unit increase in that specific feature, assuming all other features stay the same. For example, a negative coefficient for $Pclass$ would mean that as the class number increases (moving from 1st to 3rd class), the fare price generally decreases.

3. Why did we use mean_squared_error to evaluate the regression model but accuracy_score for the classification model? Why wouldn't accuracy be a good metric for the fare prediction task?Mean Squared Error (MSE) measures "how far off" a prediction is. In regression, being off by $1 is much better than being off by $100, so we need a metric that calculates the distance between numbers.Accuracy Score simply measures "right vs. wrong." In classification, you either correctly identified the category or you didn't.Why accuracy fails for Fare: Accuracy requires an exact match. If the actual fare was $50.00 and the model predicted $49.99, accuracy would call that a "fail" (0%), even though the prediction was excellent. MSE recognizes that $49.99 is nearly perfect.
